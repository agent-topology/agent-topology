# LangGraph TypeScript research

The initial independently evidenced baseline is LangGraph.js 1.4.14. Its
[dossier](1.4.14/dossier.md) records the immutable upstream source surfaces and
the minimum behavioural probe used by the producer.

Do not infer TypeScript support from Python source findings or conformance
results. Only the fixture meanings are shared. A later LangGraph.js release
must repeat the TypeScript probes and the complete shared fixture suite before
it enters the tested-version manifest.
