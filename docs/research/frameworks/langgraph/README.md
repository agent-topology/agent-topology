# LangGraph research

LangGraph has separate Python and TypeScript implementations with independent
package versions and potentially different introspection surfaces. Research is
therefore stored under an implementation language before its exact release.

Cross-language comparison belongs here only after both implementations have
independently verified the same topology concept. A Python source finding must
not be copied into the TypeScript catalog as evidence.

The shared conformance fixtures define equivalent meanings across producers;
the probes under each language version record how that implementation exposes
those meanings.
