# 0.1 contract reconciliation

- Issue: [#44](https://github.com/milocosmopolitan/agent-topology/issues/44)
- Date: 2026-09-10
- Contract authority: [`spec/agent-topology.schema.json`](../../spec/agent-topology.schema.json)
- Fixture authority: [`conformance/fixtures`](../../conformance/fixtures)

## Result

The Python producer, TypeScript producer, shared fixtures, and trace-correlation
consumer agree on the provisional 0.1 document contract. The review found three
implementation defects in the evidence path, all corrected here: the Python
research catalog lagged its executable 1.2.10–1.2.11 compatibility contract, and
the TypeScript workflows lacked the Python parity-test runtime and installed the
LangGraph.js producer's local specification dependency before that dependency
had build output. None changes the document shape, canonical form, hash
projection, or framework boundary.

No observed core mismatch was normalized away. The shared runners compare graph
structure, joins, structure hashes, completeness and element-local gaps, complete
normalized documents, and—in TypeScript—canonical UTF-8 bytes. Their explicit
normalization boundary is reviewed below.

## Version and decision check

This reconciliation changes evidence documentation and a CI build order only.
`topologyVersion` remains `0.1`, structure-hash `algorithmVersion` remains `1`,
and package versions remain independently owned. No format transition, dual-hash
transition, schema edit, fixture fork, or new ADR is required. ADR 0001, 0002,
0003, 0005, and 0006 continue to govern the resulting boundary.
