# v0.1.0-beta.1 public preview

`agent-topology` 0.1 is a public preview of a derived, descriptive manifest for the
internal shape of an agent workflow. The document contract is provisional and pre-1.0:
it has been exercised by Python and TypeScript implementations of the LangGraph model,
but not by a structurally different framework, so this release does not claim vendor
neutrality or v1 stability.

The coordinated [`v0.1.0-beta.1`](https://github.com/agent-topology/agent-topology/releases/tag/v0.1.0-beta.1)
tag identifies the reviewed release source. The four immutable registry artifacts were
qualified and published from the ancestor commits below. The corresponding package
source trees did not change between those commits and the coordinated source.

## Install

Python document utilities:

```bash
python -m pip install "agent-topology-spec==0.1.0b1"
```

Python LangGraph producer and the `agt` command:

```bash
python -m pip install "agent-topology-langgraph==0.1.0b1"
```

TypeScript document utilities:

```bash
npm install @agent-topology/spec@0.1.0-beta.1
```

TypeScript LangGraph.js producer and its specification peer:

```bash
npm install @agent-topology/spec@0.1.0-beta.1 @agent-topology/langgraph@0.1.0-beta.1
```

## Compatibility and interfaces

| Package                                  | Runtime          | Framework compatibility |
| ---------------------------------------- | ---------------- | ----------------------- |
| `agent-topology-spec` 0.1.0b1            | Python 3.11–3.14 | No framework dependency |
| `agent-topology-langgraph` 0.1.0b1       | Python 3.11–3.14 | LangGraph 1.2.10–1.2.11 |
| `@agent-topology/spec` 0.1.0-beta.1      | Node.js 20+      | No framework dependency |
| `@agent-topology/langgraph` 0.1.0-beta.1 | Node.js 20+      | LangGraph.js 1.4.14     |

Only the listed framework releases have conformance evidence. Both producers refuse
untested framework versions before inspecting a graph. `agt describe` is provided only
by the Python `agent-topology-langgraph` distribution; the TypeScript packages do not
publish an `agt` executable, producer discovery, or `agt diff`.

## First demonstrated consumer

The [topology-to-trace correlation example](../../examples/trace-correlation/README.md)
replays deterministic, sanitized evidence from a real LangGraph execution against a
canonical topology document. From a source checkout, its checked-in result is verified
with:

```bash
uv run --project packages/python/langgraph --group test python examples/trace-correlation/correlate.py --check
```

The example distinguishes matched, unmatched, unobserved, ambiguous, and insufficient
evidence while preserving topology gaps and producer limitations. It does not add
rendering, policy verdicts, or path-coverage claims to the core contract.

## Known limitations

- The core boundary remains provisional until a structurally different framework
  supplies evidence.
- Conditional destinations that were not declared may be absent and are reported as
  graph-specific gaps.
- Nested graphs are opaque by default; opt-in deep traversal remains unreliable past
  two levels in at least one supported framework.
- Runtime-built graphs are snapshots, and runtime-only behavior cannot be inferred.
- Branch versus fan-out semantics are not established, and LangGraph sentinel nodes
  remain visible under `x-langgraph`.

Consumers must surface `completeness` and `producerLimitations` rather than presenting
uncertain topology as complete. If a future publication is interrupted, follow the
[partial-publication recovery path](../releasing.md#recovering-a-partial-publication):
keep correct immutable artifacts, investigate ambiguous registry responses, and publish
a corrected version instead of rewriting an accepted artifact.
