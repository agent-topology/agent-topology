## Changes from beta.2

- Both specification packages now spell `x-*` extension numbers per
  [ADR 0009](../decisions/0009-numeric-canonical-form.md)'s byte oracle instead
  of each runtime's default float formatting, and both reject a bare JSON
  integer literal beyond magnitude `2^53`. This changes full-document
  canonical bytes for documents with a numeric `x-*` extension value; it does
  not change `structureHash` (no core field is numeric). Do not assume
  full-document byte parity with beta.2 for a document that carries a numeric
  extension. See the [numeric canonical form section](../0.1-contract.md#numeric-canonical-form).
- Documented the explicit boundary between ordinary-edge connectivity and
  first-trigger/once-only/reset firing policy: no convergence firing-policy
  fact is added by experimental interpretation revision 1, and this is not an
  OR-convergence implementation. See the
  [consumer guide](../guides/consuming-documents.md#or-convergence-and-first-trigger-firing).
- Both LangGraph producers add experimental revision 1 `entry` facts
  distinguishing observed graph roots from confirmed execution entry points.
- Both LangGraph producers add experimental revision 1 sentinel roles from
  framework-owned identity and positive user-node membership.
- Both LangGraph producers add experimental revision 1 branch interpretation
  from inspected declarations.
- Every experimental extension above is additive: core nodes, edges, joins,
  `entryNodeIds`/`exitNodeIds`, completeness gaps, and `structureHash` are
  unchanged. Extension equality is not established by equal structure hashes.
- Current source adds `derived_join_edges` (Python) and `derivedJoinEdges`
  (TypeScript) join-consumption helpers for already-validated structures.
  These are unreleased; beta.2 packages do not export them. See the
  [join connections section](../guides/consuming-documents.md#join-connections).
- Producer-generated consumer fixtures now validate cross-language extension
  semantics and legacy/extension-unaware consumption against real Python and
  TypeScript producer output (F1–F6 disposition).
- Expanded ESM installation guidance is unchanged in substance from beta.2;
  see [troubleshooting](../guides/troubleshooting.md#esm-installation-errors).

See the [Unreleased changelog](../../CHANGELOG.md#unreleased) for detailed
evidence and links.
