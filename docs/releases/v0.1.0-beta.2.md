## Changes from beta.1

- Expanded child graphs produce an `expanded-subgraph-metadata` gap when child
  declarations are not fully inspected. Python strict mode now rejects these
  incomplete views and retains the document in `IncompleteTopologyError.document`.
- TypeScript structural identifier lists and generated join IDs use Unicode
  code-point order consistently with Python. Affected non-BMP identifiers can
  change canonical output and hash values; the existing hash projection is unchanged.
- All four package artifacts contain the MIT license notice. Python distributions
  also include README descriptions and project links.
- Consumer guides, runnable examples, API/CLI references, troubleshooting, and
  future static-site guidance now start at the [documentation home](../README.md).
- Release workflows use quoted dispatch input, require an RC branch and
  source-matching versions, and package CI covers RC branches.
