# Consuming topology documents

[Documentation home](../README.md) · [Concepts](concepts.md)

Install only the specification package when your input is already JSON. You do not
need LangGraph or a producer. Validate at the boundary, check the recorded hash if
needed, and preserve uncertainty alongside the structure.

## Python

```bash
python -m pip install "agent-topology-spec==0.1.0b1"
```

Save this as `inspect_topology.py` beside a `topology.json` generated by the
[quickstart](../getting-started/python.md):

```python
import json
from pathlib import Path

from agent_topology.spec import compute_structure_hash, validate_document

document = json.loads(Path("topology.json").read_text(encoding="utf-8"))
errors = validate_document(document)
if errors:
    raise ValueError("Invalid topology:\n" + "\n".join(errors))

if compute_structure_hash(document) != document["structureHash"]:
    raise ValueError("The recorded structure hash does not match the document")

for graph in document["graphs"]:
    print(graph["id"], len(graph["structure"]["nodes"]), "nodes")
print("Completeness:", document["completeness"]["status"])
for gap in document["completeness"]["gaps"]:
    print("Gap:", gap["code"], gap["element"], gap["message"])
for limitation in document["producerLimitations"]:
    print("Limitation:", limitation["code"], limitation["message"])
```

Run `python inspect_topology.py`.

## TypeScript / JavaScript

```bash
npm install @agent-topology/spec@0.1.0-beta.1
```

Save this as `inspect-topology.mjs` beside `topology.json`:

```javascript
import { readFileSync } from "node:fs";
import { computeStructureHash, validateDocument } from "@agent-topology/spec";

const value = JSON.parse(readFileSync("topology.json", "utf8"));
const result = validateDocument(value);
if (!result.valid) {
  throw new Error(`Invalid topology: ${JSON.stringify(result.errors)}`);
}
const document = result.document;
const actual = computeStructureHash(document);
const recorded = document.structureHash;
if (actual.algorithm !== recorded.algorithm ||
    actual.algorithmVersion !== recorded.algorithmVersion ||
    actual.value !== recorded.value) {
  throw new Error("The recorded structure hash does not match the document");
}

for (const graph of document.graphs) {
  console.log(graph.id, graph.structure.nodes.length, "nodes");
}
console.log("Completeness:", document.completeness.status);
for (const gap of document.completeness.gaps) {
  console.log("Gap:", gap.code, gap.element, gap.message);
}
for (const limitation of document.producerLimitations) {
  console.log("Limitation:", limitation.code, limitation.message);
}
```

Run `node inspect-topology.mjs`.

## Validation and integrity are separate

Validation checks schema shape, identifier uniqueness, graph-element references,
and the relationship between gaps and completeness. It does **not** recompute the
stored hash. The examples above explicitly compare it with a fresh computation.

A hash match is not authentication: anyone who edits a document can compute a new
hash. Retain trusted provenance or artifact-signing evidence separately when your
application needs to know who produced it.

`canonical_json` and `canonicalStringify` serialize a document deterministically.
`finalize_document` and `finalizeDocument` replace its hash and return a canonical
copy. These utilities are not validators; validate externally supplied JSON before
calling them. Re-finalizing a received document before checking its recorded hash
would hide a mismatch.
